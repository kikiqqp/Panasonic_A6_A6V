# 整合到 A6 伺服馬達選型網頁

## 光電素子頁已先做好

- 右上角已有「返回 A6 伺服選型」按鈕。
- 可用網址參數指定返回網址：

```text
photoelectric/index.html?back=https%3A%2F%2Fyour-a6-site.example%2F
```

- 也可改按鈕文字：

```text
photoelectric/index.html?back=https%3A%2F%2Fyour-a6-site.example%2F&backLabel=返回A6選型
```

## A6 頁右上角按鈕範例

把 `PHOTOELECTRIC_URL` 換成光電素子頁上雲端後的正式網址，把 `A6_URL` 換成 A6 頁正式網址。

```html
<a class="tool-switch" href="PHOTOELECTRIC_URL?back=A6_URL">光電素子選型</a>
```

建議 CSS：

```css
.tool-switch {
  display: inline-flex;
  align-items: center;
  height: 38px;
  padding: 0 14px;
  border: 1px solid #d8dee8;
  border-radius: 999px;
  color: #617085;
  background: #fff;
  text-decoration: none;
  font-weight: 700;
}

.tool-switch:hover,
.tool-switch:focus {
  border-color: #0f766e;
  color: #0f766e;
  outline: none;
}
```

## 建議雲端路徑

- A6 主頁：`/a6-servo/`
- 光電素子頁：`/photoelectric/`

正式部署後，A6 按鈕可連到：

```text
/photoelectric/?back=/a6-servo/
```

## BOM / A6 詢價表整合關鍵字

光電素子頁加入 BOM 時，會使用與 A6 詢價表相同的資料欄位：

```js
{
  category: "光電素子",
  model: "PM-F65",
  spec: "",
  qty: 1,
  note: "",
  key: "光電素子|PM-F65||"
}
```

若該光電素子需要外接 2M 線，加入 BOM 時會自動追加一筆線材：

```js
{
  category: "連接線",
  model: "CN-14A-C2-YY",
  spec: "外接2M線",
  qty: 1,
  note: "線需單獨購買",
  key: "連接線|CN-14A-C2-YY|外接2M線|線需單獨購買"
}
```

目前先獨立存在瀏覽器：

```js
localStorage.getItem("panasonicA6QuoteItems")
```

之後整合進 A6 專案時，可在 A6 的 `quoteItems` 初始化後讀取這個 key，或直接把光電素子頁的 `state.bomItems` 併入 A6 的 `quoteItems`。同型號同規格的判斷方式一樣使用：

```js
`${item.category}|${item.model}|${item.spec}|${item.note ?? ""}`
```

加入 BOM 時也會觸發事件，若兩頁合併成同一個 SPA，可直接監聽：

```js
window.addEventListener("panasonic-bom-item-added", (event) => {
  // event.detail 就是 A6 詢價表格式的 item
});
```
